# FY-01 装机实验室 · Three.js 交互式装机拆解

**在线预览：** https://bbw-github.github.io/fy01-teardown/

菲远 FY-01 纯白 ITX 主机的可交互 3D 拆解页。全部几何体、材质、贴图与灯光均由 Three.js / Canvas 在运行时生成，没有使用外部 3D 模型或 3D 代码生成服务。

## 启动

```powershell
cd 'F:\deepseek harness'
& 'C:\Users\BianBoWen\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe' serve.py 4174
```

浏览器访问：

**http://127.0.0.1:4174/index.html**

也可以直接用任意静态服务器托管本目录。`serve.py` 提供 HTTP Range 支持，便于视频/媒体调试；对纯页面预览使用 `python -m http.server` 也可以。

## 配置

- CPU：英特尔 i5-14490F
- 主板：精粤 B760I GAMING + Intel AX201
- 显卡：艾尔莎 RTX 5060 幻影者 8G 黑色，173mm
- 内存：疆珑 i9 龙雪 RGB DDR4 8G ×2（白色，RGB）
- 硬盘：七彩虹 CN600 2TB PRO 裸条 + 白色 4mm 散热马甲
- 电源：九州风神 PS650G-FE 白色 650W SFX
- 散热：利民 SI-100 白色塔体 + 丛林豹星际积木 V4 LCD 白色正叶
- 机箱：菲远 FY-01 白色，三面玻璃
- 风扇：利民 TL-B8W ×2（顶部进风）、TL-8015W ×2（后部排风）

## 交互

- 左键拖动旋转，滚轮缩放，右键拖动平移
- 点击部件：发光高亮、显示参数并拆解
- 点击已拆解部件或详情按钮：单独装回
- 一键拆解 / 复原：按装配顺序展开或恢复
- 自动旋转、五个视角预设（ISO / 左 / 正 / 顶 / 后）、聚焦、标注开关、操作指南
- 桌面端三栏布局；手机端自动切换为抽屉面板

## 布局校正说明

根据用户提供的装机视频（Hay哥ITX《菲远FY01:送给老婆的纯白迷你海景房》）和后续实物反馈重新核对了内部结构：

- 以**中间这面玻璃为正面**：主板朝向中玻璃，丛林豹 V4 LCD 风扇正对中玻璃，背板风扇位于主板后侧
- 显卡从竖直位置**向前倒下**：水平放置、风扇朝下、背板朝上；长边左右横向，铜管保持原位置并朝向中间玻璃。原两个无意义白色垫片已删除，连接边重建为 PCIe 4.0 x16 金手指
- 显卡不再压住电源：电源移入**机箱背仓**，风扇朝向机箱后方，全模组接口面朝向右侧玻璃
- 整个前部硬件平台保持相对位置整体向中间玻璃前移 15mm，消除背仓电源与前部的穿插
- 机箱左 / 中 / 右三面玻璃之间**取消竖向立柱**，三块玻璃直接对缝；右侧玻璃内不再有主板托盘
- 机箱后部与顶部风扇开孔均采用**点状镂空出气格栅**
- 120mm LCD 风扇整体略向左移，塔体同步左移，正对风扇后方，并露出右侧两条发光 DDR4 内存
- 顶部双 80mm 进风、后部双 80mm 薄排风的位置与朝向重新核对
- 主板、内存、M.2、电源与线材的相对关系按视频中的装配顺序整理
